# Number Array

Небольшая консольная программа на C++20 для обработки массива случайных чисел с использованием алгоритмов STL.

## Что делает программа

Программа создаёт набор случайных целых чисел и последовательно выполняет над ним несколько операций:

- генерирует вектор из 100 случайных чисел в диапазоне от 1 до 1000;
- выводит исходные значения;
- сортирует числа по убыванию;
- находит и выводит простые числа;
- удаляет повторяющиеся значения;
- вычисляет сумму квадратов оставшихся элементов.

Основная логика вынесена в класс `NumberArray`, который хранит вектор чисел и предоставляет методы для генерации, сортировки, поиска простых чисел, удаления дубликатов и вычисления суммы квадратов.

## Структура проекта

```text
.
├── CMakeLists.txt
└── src
    ├── main.cpp
    └── number_array.h
```

`main.cpp` содержит пример использования класса `NumberArray` и выводит результат работы программы в консоль.

`number_array.h` содержит реализацию класса `NumberArray`.

## Требования

Для сборки проекта нужны:

- компилятор с поддержкой C++20;
- CMake версии 3.12 или выше.

Внешние библиотеки не требуются.

## Сборка

Из корневой директории проекта выполните:

```bash
cmake -S . -B build
cmake --build build
```

После сборки исполняемый файл будет находиться в директории `build` или в одной из её поддиректорий, в зависимости от используемого генератора CMake.

## Запуск

На Linux или macOS:

```bash
./build/numArray
```

## Пример вывода

```text
Original numbers:
534 72 991 72 ...

Sorted descending:
991 876 534 72 ...

Prime numbers:
991 ...

Without duplicates:
72 534 876 991 ...

Sum of squares: 1971533
```

Так как числа генерируются случайно, конкретный вывод будет отличаться при каждом запуске.
