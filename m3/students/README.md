# Students

Небольшой консольный проект на C++20 для хранения и обработки рейтингов студентов.

## Что делает

Программа читает данные о студентах из входного потока, сохраняет их во внутренней коллекции и позволяет вывести:

- список студентов с рейтингами;
- студента с максимальным рейтингом;
- средний рейтинг по всем сохранённым студентам.

Данные хранятся в `std::map`, поэтому при выводе список студентов упорядочен по имени.

## Формат входных данных

Одна строка описывает одного студента в формате:

```text
Name - rating
```

Пример:

```text
Alice - 5
Bob - 4
Charlie - 3
```

Имя и рейтинг отделяются последовательностью ` - `. Пробелы по краям имени и рейтинга удаляются при чтении.

Строки без ожидаемого разделителя игнорируются. Если имя или рейтинг пустые, либо рейтинг не является положительным целым числом, программа выбрасывает исключение `std::invalid_argument`.

Если студент с таким именем уже был добавлен, его рейтинг перезаписывается новым значением.

## Требования

Для сборки нужны:

- компилятор с поддержкой C++20;
- CMake версии 3.12 или новее.

Для сборки тестов используется Catch2. Если Catch2 не найден в системе, он будет загружен через CMake `FetchContent`.

## Сборка

Из корня проекта:

```bash
cmake -S . -B build
cmake --build build
```

После сборки исполняемый файл будет находиться в директории `build`.

## Запуск

```bash
./build/students
```

Программа создаёт тестовый набор студентов внутри `main.cpp`, выводит список студентов, студента с максимальным рейтингом и среднее значение рейтинга.

Пример вывода:

```text
A - 5
B - 4
C - 2
Z - 3
---------------
A - 5
---------------
3.5
```

## Сборка и запуск тестов

Тесты отключены по умолчанию. Чтобы собрать проект вместе с тестами, нужно включить опцию `BUILD_TESTING`:

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

Тесты проверяют чтение данных, сортировку вывода по имени, перезапись рейтинга при повторном имени, обработку некорректных строк, поиск максимального рейтинга и расчёт среднего значения.
