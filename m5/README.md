# Thread Pool

Проект на C++20 с реализацией простого пула потоков. Проект демонстрирует добавление задач в потокобезопасную очередь, выполнение задач несколькими рабочими потоками и получение результата через `std::future`.

## Возможности

- создание пула с заданным количеством рабочих потоков;
- добавление задач через `ThreadPool::Enqueue`;
- передача аргументов в задачи;
- получение результата выполнения через `std::future`;
- поддержка задач без возвращаемого значения;
- безопасное ожидание задач в очереди через `std::condition_variable`;
- остановка пула через `Shutdown`;
- автоматическое завершение рабочих потоков в деструкторе;
- синхронизированный вывод из разных потоков через `std::osyncstream` в демонстрационном примере.

## Структура проекта

```text
.
├── CMakeLists.txt
├── README.md
└── src
    ├── main.cpp
    └── thread_pool.h
```

`thread_pool.h` содержит основную реализацию:

- `TasksQueue<Task>` — потокобезопасная очередь задач;
- `ThreadPool` — пул рабочих потоков, который принимает задачи и выполняет их параллельно.

`main.cpp` содержит демонстрацию работы пула потоков: запуск задач без аргументов, задач с аргументами, задач с возвращаемым значением и проверку исключения при попытке добавить задачу после остановки пула.

## Требования

- компилятор с поддержкой C++20;
- CMake версии 3.11 или выше.

## Сборка

Из корня проекта выполните:

```bash
cmake -S . -B build
cmake --build build
```

После сборки исполняемый файл будет находиться в директории `build`.

## Запуск

```bash
./build/thread_pool
```

На Windows путь может выглядеть так:

```powershell
.\build\thread_pool.exe
```

## Пример вывода

Порядок выполнения задач может отличаться, потому что они запускаются в разных потоках.

```text
thread ID: 139589398337216
taskname: first task
arguments: none

thread ID: 139589406729920
taskname: second task
arguments: int num
second task result: 100

thread ID: 139589415122624
taskname: third task
arguments: double num, string
result: string is PI number and num is 3.1415

exception after closing thread pool
```
